# App 2C Parini

PWA for the Seconda C class at Liceo Parini — polls, test calendar, anonymous message box, and a private dashboard for class representatives.

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Firebase (Firestore + Anonymous Auth)
- PWA (manifest + service worker)

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy on Vercel

1. Import this repository on [vercel.com](https://vercel.com)
2. No configuration needed — `vercel.json` is included
3. Deploy

The app is a PWA: it can be installed to the home screen on mobile devices and works offline.
